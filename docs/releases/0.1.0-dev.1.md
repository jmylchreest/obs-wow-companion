# OBS WoW Companion: first testing preview

If you already use OBS to record WoW, this gives you a library organised around your encounters. It can start recording from the combat log, show deaths and boss markers on a timeline, and export a clip with a small web player for your group.

This is an early preview. Please try a short recording before relying on it for raid night. Linux is the main development platform. Windows packages have automated checks, but we need more testing with real games and different setups. macOS is not included.

## Download

Choose `owc-app-x86_64-pc-windows-msvc.zip` for Windows or `owc-app-x86_64-unknown-linux-gnu.tar.xz` for Linux. Extract the whole archive and run `obs-wow-companion.exe` or `obs-wow-companion`. You do not need Rust.

Install OBS Studio and FFmpeg/ffprobe separately. Windows needs WebView2 Runtime; Linux needs GTK 3 and WebKitGTK 4.1. These packages are unsigned. SHA-256 checksums are provided alongside the downloads.

## What to try

- Set up OBS, enable `/combatlog`, and record a raid pull or key.
- Click a death, slow down the replay and switch audio tracks.
- Close and reopen OBS while Companion stays open.
- Export a short player bundle and open it after extracting the ZIP.

Raid difficulty and key-level filters are available per WoW installation. Delves are experimental and off by default. Classic and PvP have parser coverage, but still need real-client validation. If OBS is already recording when Companion connects, that recording remains under your control.

Automatic clip preparation can resume after restarting Companion. Interrupted sharing exports need retrying. Missing footage is reported explicitly; recovery cannot recreate video which was never recorded.
