PLAYER GUIDE

Your first recording

Set up OBS, connect Companion and record your first pull.

This is a testing preview for Windows and Linux x86-64. Try a short recording before relying on it for raid night. OBS and FFmpeg are separate installs. What has been tested.

1. Install Companion and its tools

Choose your platform: Windows · Linux · macOS (experimental source build). OBS captures your game; FFmpeg and ffprobe prepare recordings and exports. Install all three before opening Companion.

Windows

  1. Download and install OBS Studio for Windows.
  2. Install the Microsoft Edge WebView2 Runtime if it is missing. Choose the Evergreen Bootstrapper; it installs the runtime needed by Companion’s window.
  3. Get FFmpeg from gyan.dev’s Windows builds, one of the providers linked by the FFmpeg project. Choose the release essentials ZIP, extract it to a permanent folder, and keep its bin folder intact. It contains both ffmpeg.exe and ffprobe.exe.
  4. Download the Companion Windows x86-64 ZIP. Use Extract all, then open obs-wow-companion.exe from the extracted folder. You do not need Rust.
  5. If setup cannot find the media tools, open Settings → Advanced → Media tools and enter the full paths to ffmpeg.exe and ffprobe.exe, then save preferences. There is no need to change PATH when using explicit paths.

Linux

The downloadable build is for x86-64 Linux, built on Ubuntu 24.04. Start with the OBS project’s Linux installation instructions to choose the package for your distribution.

On Ubuntu 24.04, install Companion’s desktop and media dependencies:

sudo apt update
sudo apt install libgtk-3-0t64 libwebkit2gtk-4.1-0 ffmpeg gstreamer1.0-libav gstreamer1.0-plugins-good

Download the Companion Linux x86-64 archive. Extract it in your file manager, open a terminal in the extracted folder and run:

./obs-wow-companion

Other distributions need equivalent GTK 3, WebKitGTK 4.1 and GStreamer packages. See FFmpeg’s Linux package links for media tools. Install FFmpeg on the host even if OBS is a Flatpak: Companion needs to run ffmpeg and ffprobe itself. Older distributions may need a source build; the Ubuntu archive is not a universal Linux package.

macOS — experimental

There is no Mac app download or installer yet. Automated macOS tests cover the service, media tools and crash recovery, but native playback and real WoW/OBS capture still need testing. If you are comfortable building from source, you can try the current code:

  1. Install OBS Studio for macOS, choosing Apple Silicon or Intel to match your Mac.
  2. Install Homebrew, following its setup instructions, then install FFmpeg (which includes ffprobe): brew install ffmpeg.
  3. Install Apple’s Command Line Tools with xcode-select --install, and install Rust using rustup. Open a new Terminal window afterwards.
  4. Build and run Companion:
git clone https://github.com/jmylchreest/obs-wow-companion.git
cd obs-wow-companion
rustup toolchain install 1.95
cargo +1.95 build --release --locked --bin obs-wow-companion
./target/release/obs-wow-companion

This builds the current development code, which may be newer than the downloadable preview. Automatic launch at sign-in is not implemented on macOS. If the app cannot store your OBS password, enter it for the current session.

Check the media tools

In PowerShell or a terminal, these commands should each print a version:

ffmpeg -version
ffprobe -version

If you use explicit paths in Companion, run those paths instead. On macOS, command -v ffmpeg and command -v ffprobe show the paths to enter under Settings → Advanced → Media tools. Restart Companion after changing PATH so it sees the new environment.

Keep the included documentation and templates with the downloaded app. Preview packages are unsigned; release notes and SHA-256 checksums are available alongside the downloads.

2. Connect OBS

In OBS, open Tools → WebSocket Server Settings, enable the server and authentication, then open Companion. Enter the port and password in setup. The usual port is 4455. Save the password securely if your system password store is available.

Keep your existing scenes and audio. Let setup choose the temporary recording folder while OBS is idle. In OBS, use Settings → Output → Advanced → Recording → Standard and enable Automatic File Splitting → Only split manually. H.264 video, AAC audio and MKV are a straightforward starting point. See OBS setup for capture and audio routing.

Picture and sound help is optional; there is no media test or confirmation checkbox. Make a short recording in OBS yourself and check that the right window and sound are present.

3. Choose WoW and enable logging

Select your WoW installation in setup, or choose its Logs folder manually. Linux installations may be inside Wine or Proton. You can add more installations later.

Enter /combatlog in WoW, or use an addon which enables logging. Finish setup and leave OBS and Companion open with Auto recording on. A fresh supported encounter starts recording. Starting the app mid-run cannot recreate its missing start; use Record now to capture from that point.

Under Settings → WoW installations → Automatic recording, choose the minimum raid difficulty and key level, or turn either off. Delves are experimental and off by default. Save preferences after changing settings.

4. Watch it back

After the encounter and configured extra footage, Companion prepares the recording. Select it and click a death to jump five seconds before it. Use the player controls to slow down, seek or change audio tracks. To share a clip, expand Export and save a player bundle.

If you started recording in OBS yourself, Companion leaves that recording under your control. Some clips may wait until you stop it in OBS. For missing footage or connection problems, see troubleshooting.
