PLAYER GUIDE

OBS setup

Keep your working OBS configuration; change only what you need.

Picture and sound

Create or use a scene which already records WoW. On Windows, start with OBS Game Capture targeting the game. On Wayland, use the available PipeWire screen/window picker. On X11, use a supported window or display source. Available choices depend on your OBS build and desktop.

Check the preview during gameplay and after restarting WoW. A connected OBS status does not prove that the capture source has the right window. Companion does not automatically reattach a source to a replacement game window.

Sources configured globally in OBS can appear in the mixer without being added to each scene. Avoid adding the same device twice. Check a saved recording, not just the moving audio meters.

Separate audio tracks

Open Edit → Advanced Audio Properties in OBS. The track checkboxes decide which sources go into each output track. Then enable those tracks under Settings → Output → Advanced → Recording.

TrackSuggested contents
1Full mix: game, microphone and voice chat
2Game only
3Microphone only
4Voice chat only, if captured separately

Name tracks under Settings → Output → Advanced → Audio. Names apply to future recordings. Companion reads names embedded in the file, otherwise it shows track numbers; it cannot infer which device produced an unnamed track.

For sharing, choose the full mix alone or combine the separate tracks. Combining both duplicates their sound. See the official OBS multi-track guide.

Recording output

Use Advanced output, Standard recording and manual file splitting. Start with MKV, H.264 and AAC, then choose a resolution, frame rate and encoder your machine can record comfortably. Without splitting, clips may need to wait for the whole OBS recording to close.

Use a dedicated temporary recording folder and a separate saved-clips folder. Both OBS and Companion must see the same files; check permissions and path access if OBS is installed through Flatpak. Keep room for source footage, saved clips and temporary exports.

Optional scene switching

Choose Settings → OBS → Recording scene to use a particular scene for Companion recordings. Companion reads the current scene before switching and returns to it afterwards, provided you have not selected another scene yourself. Clear this setting to keep the current scene.

Scene switching is unavailable while streaming. Clear the scene override if you want to record while streaming. OBS uses the program composition; Companion does not create a separate game-only output or control your stream.

Connection and saved passwords

Enable OBS WebSocket authentication under Tools and enter its password in Companion setup. Settings → General → Run setup wizard reopens setup using your current configuration. You can close the wizard to browse existing recordings.

Saved passwords use the operating system password store. If it is locked or unavailable, unlock it or enter the OBS password for this session. Companion retries connections automatically but does not start OBS. See connection troubleshooting.

Optional fresh setup

Release archives include templates/obs/OWC-Starter and OWC-Starter-scenes.json. Import the profile through OBS's Profile menu and the scene collection through its Scene Collection menu. They are separate resources. The starter uses 720p/30, x264, MKV and two AAC tracks with manual splitting. Select your own sources, devices and temporary recording folder afterwards.

Keep your previous profile and collection so you can switch back. Imports do not configure your WebSocket password. The legacy JSON recipe is a checklist, not an OBS import.
