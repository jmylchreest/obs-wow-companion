PLAYER GUIDE

What has been tested

A testing preview, with clear limits on what we can promise.

The first preview is 0.1.0-dev.1. Linux and Windows packages, native desktop/service checks, media tests, crash recovery and installers passed the tagged release checks. That is not a guarantee for every game, encoder or desktop.

Platforms

PlatformEvidence and limits
Linux x86-64Main development platform. Isolated X11/OBS and WebKit tests pass; real Retail raids and keys have been used during development. GNOME/KDE Wayland capture and longer sessions need further testing.
Windows x86-64Native package, credential store, desktop, service/media, crash-recovery and installer checks pass. Real OBS/game capture, audio and long sessions need player testing.
macOSCurrent source passes workspace, FFmpeg/ffprobe, service and crash-recovery checks on the macOS 14 runner. No packaged app yet; native playback and WoW/OBS capture are not qualified. See the experimental source-build instructions.
Other architecturesNo preview packages or support claim.

The latest platform validation also passed media-tool discovery with spaces and Unicode paths on Linux, Windows and macOS, plus Linux/Windows package and installer checks. These checks cover current development code, not a new published release.

Game modes

ActivityCurrent position
Retail raids and Mythic+Implemented, with synthetic tests and development-host gameplay. Wider client/build qualification is still needed.
Arena, skirmish, Solo Shuffle and battlegroundsParser/state-machine coverage exists; real-client validation remains incomplete.
Classic variantsFlavour selection and supported event handlers exist. Each client version and activity still needs qualification.

Media and capture limits

OBS handles capture, audio and recording encoders. The initial tested configuration is H.264/AAC in MKV with manual splitting. FFmpeg and ffprobe are installed separately. Playback depends on the OS/browser decoder; Companion can prepare a compatible copy when needed.

Advanced export settings offer CPU, NVENC, QSV, AMF and Linux VAAPI. Unavailable choices fall back to CPU. VAAPI has development-host evidence; the other GPU choices still need hardware-specific qualification. There is no universal GPU or zero-frame-loss guarantee.

Missing pre-roll cannot be invented. Recovery requires retained footage with trustworthy timing. There is no Warcraft Logs upload/API integration, automatic source reattachment, cloud library, multi-POV editor or Warcraft Recorder library import.

Successful test reports are useful too. Start with a short pull or key, check the markers and audio, then try a player-bundle export. Tell us how it went.
