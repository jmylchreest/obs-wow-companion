# companion-glib-security-backport

**Decision:** Patch crates.io GLib 0.18.5 through vendor/glib with the two-line upstream VariantStrIter output-pointer correction. Verify the vendor tree against upstream hashes and run optimised iterator regression coverage. Remove the patch when Tao/Wry permit a patched upstream GLib.

## Rationale

The current GTK3 desktop dependency graph cannot use GLib 0.20, and no compatible registry release fixes RUSTSEC-2024-0429. Keep transitive unsoundness checks enabled rather than suppressing this advisory.
