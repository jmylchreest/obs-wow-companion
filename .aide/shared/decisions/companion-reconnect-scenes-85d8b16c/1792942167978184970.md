# companion-reconnect-scenes

**Decision:** Reconnect automatically with bounded 2-to-30-second backoff, reuse only OS-stored or authenticated in-memory session credentials, and revalidate OBS without restoring capture ownership. Optional recording-scene selection applies only to companion-started recordings; restore the previous program scene only while not streaming and absent user scene/profile changes or disconnect.

## Rationale

User leaves the companion open while cycling OBS and requested a configurable recording scene with restoration. OBS program scenes also affect streaming.
