# companion-capture-events

**Decision:** Use a bounded typed event bus for OBS WebSocket events with generation checks and a single serialized capture controller for OBS and parsed combat-log lifecycle events. Push changed UI snapshots over authenticated SSE with snapshot-on-reconnect. Fresh supported activity starts automatically record after setup; overlapping activities and manual clips retain capture until post-roll. Pause persists. Never stop user-owned OBS recordings or fabricate pre-roll.

## Rationale

User requested event-driven recording lists, combat-log-triggered recording, and an internal event bus with an OBS WebSocket publisher.
