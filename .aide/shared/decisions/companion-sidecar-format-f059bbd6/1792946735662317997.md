# companion-sidecar-format

**Decision:** Retain versioned companion JSON sidecars beside MKV exports, including all activity markers, export timing and media metadata. Atomically update saved sidecars for manual markers and annotations. Preserve markers when trimming. Do not claim Warcraft Recorder compatibility: its MP4 metadata schema lacks equivalent generic manual markers and installation provenance.

## Rationale

User requested portable marker metadata and asked whether the upstream format can be reused; inspected upstream types and writer at 2643938980b9fe2031aa17275d3ee528bd2fd20e.
