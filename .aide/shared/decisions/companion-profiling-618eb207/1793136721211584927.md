# companion-profiling

**Decision:** Keep timing traces opt-in through the profiling Cargo feature and --profile-trace; capture only named timing spans without arguments or log events. Use synthetic Criterion baselines before retaining optimisations.

## Rationale

Default builds should not collect profiles; traces must not expose private session URLs or credentials. Measurements distinguish useful changes from speculative tuning.
