# companion-date-range

**Decision:** Use one calendar range-picker control in library filters, with draft start/end selection and explicit Apply. Escape, Cancel and outside pointer clicks discard edits. An adjacent clear control and All dates inside the dialog immediately reset both bounds. Dates retain local-calendar inclusive range semantics.
