# companion-sharing

**Decision:** The sole UI share export is an atomic no-overwrite ZIP with local-assets player, H.264/AAC MP4 and versioned allowlisted metadata. Keep range, full-width destination, track choices and Export ZIP action inside one panel. Default to track 1; allow multiple tracks mixed with normalized amix into one AAC stream or none for silent export. Pin media and block deletion/quit while sharing; interrupted jobs require retry.
