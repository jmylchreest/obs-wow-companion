# companion-credential-storage

**Decision:** Store authenticated OBS passwords only in the OS credential store: Windows Credential Manager or Linux Secret Service. Scope entries by companion data-profile UUID and loopback OBS port. Save on successful explicit connection checks when enabled; allow blank-password reuse and explicit deletion. Never use plaintext config, SQLite, browser storage or logs as a fallback. Credential-store failures must be visible and must not misreport a successful session connection as a saved credential.

## Rationale

User explicitly requested secure persistence on Check again to remove repetitive onboarding.
