# companion-manual-markers

**Decision:** Publish boss start/end and player-death marker events independently of detected activities. Bind each manual clip to one configured installation UUID and attach matching markers from its recording interval, before automatic activity filters. Select the source automatically for one installation and explicitly in the UI for multiple.

## Rationale

Manual recording begun mid-dungeon must retain subsequent review markers without needing the missed dungeon start and without mixing installations.
