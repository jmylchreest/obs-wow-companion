# companion-media-timing

**Decision:** Use precise re-encoding for automatic encounter exports; offer explicit keyframe-aligned fast trims with the actual start persisted.

## Rationale

Stream-copy seeks can move the visible start and invalidate marker timestamps. Automatic exports prioritize truthful timing; manual fast cuts expose their adjusted origin.
