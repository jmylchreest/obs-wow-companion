# companion-product-boundary

**Decision:** Build a cross-platform Rust companion for separately installed OBS Studio, targeting Linux and Windows.

## Rationale

The user selected an OBS companion so existing OBS capture, audio and scenes can be reused on both platforms.

## Details

OBS owns capture and encoding; the companion owns WoW log parsing, activity detection, clip organisation and review. See docs/specification.md for proposed release scope.
