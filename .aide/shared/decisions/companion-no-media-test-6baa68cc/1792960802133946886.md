# companion-no-media-test

**Decision:** Do not expose a synthetic media test, test player or diagnostic media-generation action in the application. Onboarding uses OBS preview/audio guidance and normal recording playback. Automated UI fixtures are generated externally and silent; signal-based media unit fixtures remain test-only and are never played.

## Rationale

User requested removal of the entire in-app media test because it adds friction and can cause audible test tones.
