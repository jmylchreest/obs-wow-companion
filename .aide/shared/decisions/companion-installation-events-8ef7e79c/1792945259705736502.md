# companion-installation-events

**Decision:** Persist a UUID per installation. Dedicated combat-log watchers publish source-identified Started, Updated, Finished and Abandoned batches through the bounded controller bus and wait for checkpoint acknowledgement before advancing. Preserve one serialized OBS capture controller and one OBS output.

## Rationale

Separate parsing from recording orchestration and retain installation identity for future multiple-input support without claiming separate capture outputs today.
