# companion-ui-actionable-settings

**Decision:** Present settings like a desktop application: conventional concise labels, compact status rows and expandable help. Lead unresolved checks with the next concrete action and place the fix beside the problem. Collapse passed checks and technical details. Prefer outcome-oriented language such as Use recommended folder over internal terms such as spool; where OBS changes are manual, give exact steps and a recheck action. Avoid promotional headings and repeated descriptive cards.

## Rationale

User found the wizard too web-like and descriptive; they want naturally intuitive guidance that tells them how to fix each issue.
