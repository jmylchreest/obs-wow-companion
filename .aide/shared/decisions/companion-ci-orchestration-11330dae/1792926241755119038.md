# companion-ci-orchestration

**Decision:** Maintain explicit GitHub Actions workflows around cargo-dist packaging; permit only cargo-dist CI-generation drift with allow-dirty=[ci]. Publication requires successful tag validation, quality and complete verified Linux/Windows bundles.

## Rationale

The generated cargo-dist host condition allowed skipped build jobs, which could admit publication after a failed prerequisite. Explicit workflows provide success-only publication, package/runtime verification, least-privilege job permissions, and regression tests for the release dependency graph.
