# companion-export-interaction

**Decision:** Use bordered disclosure panels with clear expanded state across the UI. Export settings default open; Download, Export and Delete are right-aligned buttons. Select range exposes draggable and keyboard-adjustable In/Out handles on the actual player seek track, including fullscreen; precise cutting is automatic. Signpost hover shows event labels and suppresses the seek tooltip; overlapping signposts stack with lower lanes in front.

## Rationale

User requested consistent native-feeling disclosure sections, familiar video-editor range selection, readable player controls and event tooltips.
