# companion-startup-readiness

**Decision:** Detect OBS through a bounded unauthenticated WebSocket greeting; run read-only settings checks in background and offer a dismissible four-step startup wizard. A closed port means unreachable, not proof that OBS is stopped. Require explicit idle-output folder changes and human picture/audio verification.

## Rationale

The companion cannot reliably infer process state across native, Flatpak and Wine setups. Greeting-based discovery confirms OBS without storing credentials or mutating capture, while source configuration and synthetic encoding cannot establish actual gameplay or microphone correctness.
