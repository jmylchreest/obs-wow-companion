# companion-desktop-runtime

**Decision:** Use Tao and Wry for the native Linux/Windows window around a bundled loopback-only authenticated UI; keep an explicit browser fallback.

## Rationale

The native window uses system WebKitGTK/WebView2 and the same local engine without an external Node runtime. GTK default_vbox integration and synthetic playback have been exercised on Linux.
