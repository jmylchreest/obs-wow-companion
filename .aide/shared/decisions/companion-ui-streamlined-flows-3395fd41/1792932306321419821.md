# companion-ui-streamlined-flows

**Decision:** Apply streamlined onboarding principles throughout the UI: one clear primary action per task; combine redundant connect/check/validate actions; detect existing state automatically; show explicit success, warnings and actionable failures; advance after successful user-triggered checks while preserving manual navigation and completed progress; allow revisiting steps and deferring optional setup; progressively disclose advanced settings; require confirmation only for meaningful consequential changes; never imply readiness beyond verified evidence. Use plain concise UI copy without em dashes.

## Rationale

User requested that the simplified OBS wizard become a general UI design principle, rather than a one-off change. Reduce unnecessary decisions and clicks while preserving visibility, control and truthful status.
