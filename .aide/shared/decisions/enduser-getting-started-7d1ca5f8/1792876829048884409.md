# enduser-getting-started

**Decision:** The first-run page gets a new user to a working result in under ten minutes, with no prior product knowledge assumed

## Rationale

New users decide whether to keep going in the first few minutes. A getting-started guide that assumes context, buries prerequisites, or ends without a visible result converts readers into bounces.

## Details

Start with install or access, then the smallest possible end-to-end flow that produces something the user can see. Link deeper topics from the end, do not scatter them through the path. Test the guide on someone who has not used the product before — if they stall, fix the guide not the reader.
