# companion-playback-audio

**Decision:** Show a named audio-track dropdown within the player only when multiple tracks are available. Playback selects one track independently from export mixing. Preserve source-wall-time position, playback speed and play/pause state across compatible-copy switches; prevent overlapping switches and discard restoration when selecting another recording.
