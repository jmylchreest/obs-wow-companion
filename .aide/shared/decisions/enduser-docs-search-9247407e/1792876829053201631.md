# enduser-docs-search

**Decision:** A user-facing docs site provides full-text search over all published versions of the docs

## Rationale

Users often know what they want to find but not where it lives. Search turns a docs site from a tree that has to be navigated into an answer engine.

## Details

Most modern docs frameworks (Docusaurus, Starlight, MkDocs-Material, VitePress, Read the Docs) ship search built-in or as a one-line configuration. Choose what fits the team — the decision is that search exists and covers every published version, not which tool provides it. For versioned docs, the search must make clear which version a result belongs to.
