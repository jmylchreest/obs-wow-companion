# companion-export-details

**Decision:** Use an asynchronous desktop save dialog beside the editable ZIP path; browser-only mode retains direct path entry. Export starts collapsed. Display embedded audio track titles with numbered fallbacks, never infer source identity from audio. Persist only the latest successful bundle per recording with measured MP4 metadata, ZIP size, path, range, tracks and completion time; show original and bundle tables side by side. Exported ZIPs remain independently owned files.
