# companion-log-file-identity

**Decision:** Detect log rotation with device/inode identity on Unix and stable volume/file IDs on Windows; never use creation time as file identity.

## Rationale

Windows-target tests under Wine showed creation timestamps changing after appends and causing duplicate reads. Stable IDs pass partial UTF-8 and persisted backlog tests.
