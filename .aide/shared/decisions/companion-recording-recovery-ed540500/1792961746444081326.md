# companion-recording-recovery

**Decision:** Persist managed OBS recording checkpoints and recover ownership after reconnect or restart only when endpoint, output path, monotonic duration and byte counters, and fresh fragment evidence identify the same unpaused recording. Restore the current fragment, scene restoration and automatic post-roll state. Invalidate checkpoints before an unconfirmed split or on pause, profile change or clock discontinuity; uncertain or unrelated recordings remain observed. Never index an already closed file twice.
