# companion-onboarding-installations

**Decision:** Support up to ten independently named WoW installations with distinct canonical Logs folders. Offer bounded discovery of known game layouts in common locations and a user-specified folder; suggest candidates without adding them automatically, preserve manual entry and per-installation filters. Existing OBS users can confirm working picture/audio without a synthetic media test. Keep FFmpeg availability checks automatic; put generated playback diagnostics behind optional troubleshooting with visible progress and results.

## Rationale

User requested intuitive installation detection, multiple installs, and removal of a redundant mandatory media test when OBS already works.
