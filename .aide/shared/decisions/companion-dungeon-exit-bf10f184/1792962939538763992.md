# companion-dungeon-exit

**Decision:** For active Mythic+ runs with a known instance map, a logged ZONE_CHANGE to another map starts a persisted 30-second exit grace period. Returning to the dungeon before expiry cancels it; further outside activity does not extend it. Expiry publishes installation-scoped DungeonExit abandonment through the existing event bus and normal owned-recording post-roll flow. Missing exit events retain inactivity and manual-abandon fallbacks.
