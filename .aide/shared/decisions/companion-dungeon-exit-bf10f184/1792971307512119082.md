# companion-dungeon-exit

**Decision:** Keep a 60-second abandonment grace after an explicit dungeon exit, cancelled by return. Default fallback is five minutes without a relevant group action or encounter boundary; aura/background traffic must not extend it. Migrate the old 30-minute default once, preserving other custom values. Expose the last action and deadline in diagnostics.
