# companion-player-timeline

**Decision:** Use an offline bundled Video.js classic HTML5 player for standard playback controls. Attach marker signposts and combat spans directly to its seek-bar element, mapped through exported video origin and actual media duration. Red spans require paired boss boundaries; orange spans are explicitly estimated from bounded group damage/miss samples, never assumed across a whole dungeon. Preserve keyboard fine seeking.

## Rationale

User rejected the bespoke playback button strip and identified differing widths between marker and seek timelines; one shared coordinate system must hold through resizing and fullscreen.
