# companion-review-ui

**Decision:** Keep the OBS pill status-only with accessible health details; open setup from Settings. Use compact recording rows with heart and lock toggles, integrated player controls and event markers, a deaths table, and autosaved label chips with suggestions derived from assigned labels.

## Rationale

User requested a less cluttered native-feeling review interface and explicitly rejected using the OBS status pill as a wizard action.
