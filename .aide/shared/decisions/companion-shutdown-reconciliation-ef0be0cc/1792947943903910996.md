# companion-shutdown-reconciliation

**Decision:** Commit manual start/finish state and activity metadata transactionally. Recover interrupted manual clips as abandoned using confirmed timeline evidence. Queue sidecar updates atomically with SQLite activity/annotation changes, clear only after atomic file replacement, and reconcile ready recordings on startup with retryable failures. Preserve unknown sidecar schemas and unindexed/open OBS footage.

## Rationale

Close the identified manual-interval restart and database/sidecar crash windows with durable checkpoints and a small reconciliation queue.
