# companion-desktop-shutdown

**Decision:** Quit and native close share requestDesktopQuit and preserve active-recording/export guards. After successful server acceptance, close frontend SSE and notify Tao directly through Wry IPC to exit the native process. Backend SSE listens for shutdown; HTTP draining is bounded to two seconds. Service completion also explicitly wakes Tao. Only browser mode shows instructions to close a window manually.
