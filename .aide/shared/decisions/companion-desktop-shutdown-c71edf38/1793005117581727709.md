# companion-desktop-shutdown

**Decision:** Quit button and native close share requestDesktopQuit. Successful shutdown closes the frontend EventSource and signals backend SSE streams to terminate so graceful HTTP shutdown can complete. The service completion task wakes the Tao event loop with an explicit user event; do not rely on periodic task polling. Preserve existing active-recording/export quit guards.
