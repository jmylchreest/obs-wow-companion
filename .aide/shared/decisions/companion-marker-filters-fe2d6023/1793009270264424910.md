# companion-marker-filters

**Decision:** Derive marker categories from recorded event kinds and synthetic activity boundaries, grouping start/end pairs generically. Persist hidden categories and global visibility. The eye opens checkbox filters with Toggle all; category filters affect associated signposts and combat bands but not the death table or stored metadata. Place signposts using the rendered seek-bar width, skip zero-width layout and reuse the lowest non-overlapping lane after rendering and resizing.
