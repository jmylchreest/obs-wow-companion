# companion-release-scope

**Decision:** Include all former MVP and 1.0 features in the first public release, together with OBS setup documentation and tested native OBS starter exports.

## Rationale

The user requested the broader feature set in the first release and OBS configuration guidance/templates.

## Details

Includes PvP, Classic coverage, live review, precise exports, audio-track selection and background operation. Internal milestones remain development checkpoints only. The current JSON recipe is design-only; profile and scene-collection exports must be generated and import-tested with supported OBS versions before release.
