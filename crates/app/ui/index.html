    Checking for OBS…

    1. Open OBS Studio. If needed, .
    2. In OBS, open Tools → WebSocket Server Settings. Enable the server and authentication.
    3. Enter the port and password shown there. Leave the password blank to use one saved earlier.

    If OBS is not reachable, it may be closed, its server may be disabled, or the port may differ. We do not start or reconfigure OBS automatically.
